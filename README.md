# CMO War Room Dashboard

Virtual CMO가 생성한 정적 HTML 브리핑을 보관·배포하는 저장소입니다.

- `index.html`: War Room 인터페이스
- `report_YYYY-MM-DD.html`: 날짜별 시장 브리핑 스냅샷

생성 로직의 원본은 `lewis-pictures-automation` 저장소에 있습니다. 이 저장소는 생성기 소스가 아니라 배포 결과물 계층이므로, 보고서 로직을 고칠 때는 먼저 자동화 저장소를 수정하고 새 결과물을 생성합니다.

## 안전 원칙

이 HTML은 외부에 게시될 수 있는 공개 결과물로 취급합니다. API 키·토큰·내부 프로필·비공개 보고서 원문을 파일에 넣지 않습니다. `index.html`의 API 키 입력값은 브라우저 로컬 저장소에만 머물러야 하며, 코드나 생성물에 하드코딩하면 안 됩니다.

날짜별 보고서는 당시 생성 결과를 보존하는 스냅샷입니다. 과거 내용을 조용히 고치지 말고, 생성기 수정과 새 보고서 발행을 우선합니다.
